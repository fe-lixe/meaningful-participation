# Changelog

Notable changes to the Meaningful Participation Protocol (MPP), the Meaningful Participation Reference Architecture (MPRA) and their supporting materials. Releases are numbered MAJOR.MINOR.PATCH, as described in section 28 of the [specification](SPECIFICATION.md).

Changes are recorded under **Unreleased** as they are merged, and move under a version heading when that version is released.

## Unreleased

Planned as patch release 1.0.1. Protocol version 1.0 and its published artefacts are unchanged.

### Added

- `mappings/`: non-normative notes on how MPP relates to other standards, starting with the Common Impact Data Standard.
- This changelog.
- A landing page at `https://fe-lixe.github.io/meaningful-participation/` listing each published protocol version and its files. Every release regenerates it; it sits outside the version folders, so published artefacts are unchanged.

### Changed

- Releases are numbered MAJOR.MINOR.PATCH. The protocol version, and so `mppVersion`, stays MAJOR.MINOR. Patch releases correct and clarify without changing normative requirements or published artefacts.

### Fixed

- White paper: Ecosystem Relationships are described as structural or delegated-authority relationships, consistent with the specification. Recognition is decided by each receiving ecosystem's interoperability policy.
- White paper: Commitment Classes are described as common rather than universal.
- White paper: the sports club example no longer classifies an ordinary social media post as Standing.
- White paper and README: the MPRA layer questions are the same in both.
- White paper: footnote 2 cites the author of the article on costly signalling.

## 1.0.0 - 2026-10-05

First stable release, tagged `v1.0`, defining protocol version 1.0. See the [release notes](https://github.com/fe-lixe/meaningful-participation/releases/tag/v1.0).
